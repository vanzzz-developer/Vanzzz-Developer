## 👨‍💻 About Me

- 🚀 **Specialization**: Building high-performance desktop applications, modern web platforms, and mobile apps with clean architectures.
- 🎬 **AI Multimedia Engineering**: Experienced in end-to-end AI pipelines — Speech-to-Text (**faster-whisper**), Speaker Diarization (**pyannote.audio**), Neural Text-to-Speech (**Edge Neural HD**), and high-throughput audio/video processing with **FFmpeg**.
